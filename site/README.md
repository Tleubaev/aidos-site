# Статическая вёрстка — Защитинский элеватор

Демонстрационная версия сайта для согласования с клиентом. Обычные HTML-файлы: работают из папки, без сервера, без сборки.

## Как посмотреть

Откройте `index.html` двойным кликом. Всё — CSS, картинки, переключение языка, кнопки WhatsApp — работает и по `file://`.

Чтобы показать клиенту по ссылке, залейте всю папку `site/` на хостинг — она самодостаточна.

| Файл | Страница |

`assets/css/site.css` — все стили, `assets/js/site.js` — переключение языка, мобильное меню, фильтр каталога и сборка ссылок WhatsApp.

## Два языка

Русский и казахский лежат в разметке рядом: `<span lang="ru">…</span><span lang="kk">…</span>`. Нужный показывается через CSS по атрибуту `data-lang` на `<html>`, выбор запоминается в браузере.

Правите текст — правьте оба варианта. Казахский перевод черновой и требует вычитки носителем.

## Как убрать демо-плашку

Оранжевая полоса сверху предупреждает, что цены и часть текстов предварительные. Перед показом «как есть» её можно снять: удалите блок `<div class="demo-bar">…</div>` в начале каждого HTML-файла.

**Не убирайте её, пока клиент не подтвердил цены** — иначе сайт выглядит так, будто цены настоящие.

## Что здесь настоящее, а что нет

**Настоящее** — взято с макетов упаковки и из данных клиента: название компании, год основания 1928, адреса на двух языках, телефоны, e-mail, стандарты ГОСТ, пищевая ценность, условия и срок хранения, фасовки 5/10/50 кг, изображения мешков.

**Предварительное, требует подтверждения** — все цены, режим работы, имя менеджера и его фото, условия доставки и оплаты, тексты «О компании». Полный список — в `../ROADMAP.md`.

## Пересборка

Страницы собираются из общего шаблона, чтобы шапка и подвал не разъехались:

```bash
node _build/build-site.js
```

Скрипт перезаписывает все HTML-файлы в `site/`. Если правите разметку руками — либо больше не запускайте сборку, либо вносите правку в `_build/build-site.js`.
